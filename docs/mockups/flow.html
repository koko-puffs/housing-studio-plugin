Housing Studio plugin · mock-up for 0.6

One flow: get, place, finish

0.5 added shopping sources, errands, clear out and swaps, set the fixtures, care checks and the site link. Each one landed as its own panel, so Ready became a long column of notes. This mock-up folds them into the path you already take: what you need, what Start does, what's left after.

One screen, three stagesGet, Place and Finish are numbered steps on Ready, not separate panels.
Chips, not paragraphsChecks and states are short chips that open a detail when you press them.
One brass buttonEach screen has a single primary action, and its words say what it will do.
Beta stays in placeExperimental features appear where they belong, with a small Beta tag. No separate pages.

Housing Studio 0.6.0 · What's new
  • Four tabs: Placing, Getting (prices, errands' limits, the site link), Beta and Help.
  • Each setting has a name and a single line saying what it does. Longer explanations move to tooltips.
  • The Beta switches are also on Ready, where they're used. This tab is just the overview.

What moves where

  • Shopping list → Ready · Get (the list opens from it)
  • Errands' estimate → Get, before setting out
  • Clear out, Swap → Ready · Place, as one choice
  • Set the fixtures → Ready · Finish and Done
  • Carry on → banner · item limit, clashes, dyes → check chips
  • Since your last run → Start · This house

What stays

The tokens, fonts, icons and controls are the ones the plugin already draws: brass is the one accent, panels are glass, and footers are walnut. Every element here is a Kit control that already exists, except the journey bar and the check chip, which are new.

Wording

The button always says what will happen: Get 12, then place · Clear out 14, then place · Swap and place · Start placing. Notes are one line. Anything longer moves behind a chip or into a tooltip.
